# 授权目录与本地文档播放接入

父提交 35b40e61f0bf96c964785c9ad05edf914f1b83c6；沿用独立 feature worktree 与 Draft72。
整体所有分支 main 准备仍未完成，G7 DO_NOT_MERGE。

## 行为

LOCAL 新建来源通过系统目录选择器取得持久读授权，主线路 URL 保存一个设备目录绑定，
保存前由真实 LocalProvider 检查目录；重新授权更新原记录。无绑定的历史来源保留应用外部私有目录。
浏览、详情、播放和同目录字幕共用 tree-backed URI，不把文档 ID 当文件路径，不混入其他来源或其他授权树。
丢失授权时返回明确目录重授权入口。可迁移备份继续排除设备绑定；本机加密回滚快照保留绑定而不恢复 OS 授权。

Media3 直接读取文档；mpv 用会话独占的文档字节源回环桥读取，内容 URI 不进入 HTTP 凭据栈。
已知长度支持单段范围请求；未知长度提供顺序流且不宣称随机访问。停止和切源关闭流、撤销旧回环地址，
迟到打开的流也不能逃逸。元数据、打开和读取均在桥工作线程进行，不复制整部影片。
